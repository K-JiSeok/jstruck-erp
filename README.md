# 제이에스매매상사 차량 정산 · 관리 시스템

Supabase(실서버) 기반으로 전환된 버전입니다. 현장 직원 여러 명이 각자 스마트폰으로 등록해도
같은 데이터를 실시간으로 공유합니다.

## 실행 방법

```bash
npm install
npm run dev
```

`.env.local`에 이미 실제 Supabase 프로젝트(`trug-project`) 키가 설정되어 있어 바로 실행됩니다.
다른 프로젝트로 옮기려면 `.env.example`을 참고해 `.env.local`을 새로 만드세요.

## 최초 1회 필수 설정 (Supabase 콘솔에서)

1. **SQL Editor**에서 스키마 SQL 실행 (대화 중 전달드린 SQL, 테이블 7개 생성)
2. **Storage**에서 버킷 3개 생성 (`receipts`, `vehicle-photos`, `vehicle-docs`, 모두 Public)
3. 관리자 화면(`/admin/employees`)에서 **직원을 최소 1명 이상 등록** — 로그인이 안 되면
   먼저 여기서 이름+PIN을 등록해야 합니다. (닭과 달걀 문제 방지를 위해 이 페이지는
   로그인 없이도 접근 가능하도록 열어뒀습니다. 실제 운영 전 보안 강화 권장)

## 로그인

- `/login` — 이름 선택 → PIN 4자리 입력
- `/worker`, `/admin/*` 모든 화면은 로그인이 필요합니다 (미로그인 시 자동으로 `/login`으로 이동)
- 로그인 세션은 브라우저에 저장되며, 로그아웃은 현장 화면 상단의 "다른 사람으로 로그인" 버튼으로 가능합니다.

## 화면 구성

| 경로 | 설명 |
|---|---|
| `/login` | 직원 로그인 (이름 + PIN) |
| `/worker` | 현장 비용/영수증 등록 (모바일 최적화, 음성입력 지원) |
| `/admin` | 정산 대시보드 (실시간 반영, 필터, 엑셀 다운로드) |
| `/admin/vehicles` | 차량 목록 (차량번호 클릭 → 상세 페이지) |
| `/admin/vehicles/[id]` | 차량 상세 — 사진/등록증/수리내역서/성능점검기록부, 매입가/판매가 등 정산정보, 광고관리, 계약완료·판매완료 처리 |
| `/admin/employees` | 직원 등록/관리 |

## 현장 직원 등록 폼 항목

등록자(로그인으로 자동 지정) · 차량번호(검색 + 미등록 시 즉시 등록) · 비용 항목(차량수리/주유/부품/실내정비/탁송/검사/타이어/배터리교체/도색/기타/세차) ·
결제방법(카드/현금/이체) · 업체명(음성입력 가능) · 영수증 사진 · 수리내용(음성입력 가능)

> 음성입력은 Chrome, 삼성인터넷 등 Web Speech API를 지원하는 브라우저에서 동작합니다.
> Safari(iOS)는 지원이 제한적일 수 있어, 지원하지 않는 브라우저에서는 마이크 버튼이 자동으로 숨겨집니다.

## 데이터 구조

- `lib/supabaseClient.ts` — Supabase 클라이언트
- `lib/types.ts` — 테이블과 1:1 매핑되는 타입
- `lib/storage.ts` — 모든 데이터 CRUD 함수 (컴포넌트는 이 함수만 호출, DB 세부구현과 분리됨)
- `lib/session.ts`, `lib/useSession.ts` — 로그인 세션 관리
- `lib/export.ts` — 엑셀 다운로드
- `lib/image.ts` — 영수증 사진 압축(업로드 전 900px/JPEG 65%로 축소)

## 보안 관련 참고사항

- 지금은 "사내 링크를 아는 사람만 접속"하는 것을 전제로, PIN 로그인 후에도 모든 로그인 사용자가
  같은 수준으로 데이터를 읽고 쓸 수 있습니다 (Supabase RLS가 전체 허용으로 열려 있음).
- 정식으로 "비회원 제한 노출", "매입자만 정산 확인" 같은 세밀한 권한 제어를 하려면
  Supabase Auth 기반의 정식 로그인 + RLS 정책 강화가 필요합니다. 다음 단계에서 진행 가능합니다.
